# LP APK Data Requirements Map

## Objetivo

Mapear as entidades minimas do APK e os requisitos que dependem de cada uma.

## Regras especificas desta fase

- `documento` continua opcional para cliente comum;
- `documento` continua obrigatorio para cliente faturado;
- `placa`, `nome` e `telefone` sao o conjunto minimo esperado para atendimento comum, distribuido entre `Vehicle` e `Customer`;
- cliente faturado exige dados completos o suficiente para faturamento e documento;
- o mapa abaixo usa contratos Web/documentais como fonte de verdade, nao o schema parcial do checkpoint Android atual.

| Entidade | Origem Web | Requisitos APK relacionados | Campos obrigatorios | Campos opcionais | Relacoes | Offline obrigatorio | Sync obrigatorio | Impressao/documento | Risco de perda | Observacao |
