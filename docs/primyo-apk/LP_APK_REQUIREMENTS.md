# LP APK Requirements

## Objetivo

Consolidar os requisitos obrigatorios do app Android oficial `LavaPrime` antes da primeira fase de codigo.

## Regras desta fase

- o Web continua como referencia funcional oficial;
- `Material_Visual` continua como referencia oficial de marca;
- o Android deve herdar rotina e linguagem do Web, mas nunca copiar layout desktop literalmente;
- requisito so sobe para `ready-for-implementation` quando ja tiver rotina Web observada ou regra programatica formal aprovada;
- quando uma necessidade futura nao fizer parte do APK operacional inicial, ela permanece em `LPFR`.

## Status permitidos

- `not-started`
- `to-map`
- `mapped`
- `needs-decision`
- `partial`
- `ready-for-implementation`
- `implemented`
- `validated`
- `blocked`
- `rejected`

## Requisitos convertidos em LPFR

- `APK-FIN-003 - Caixa` nao entra como requisito obrigatorio do APK inicial.
- o que permanece confirmado como baseline obrigatoria e `resumo financeiro mobile` + `pagamentos em aberto`.
- abertura e fechamento diario de caixa opcional continuam registrados em `LPFR-001`.
