# LP APK Phases

## Objetivo

Formalizar a matriz oficial de fases do `Programa LavaPrime APK`.

## Legenda curta

- `docs-only`: `docs/primyo-apk/**`, `docs/primyo-changes/**`, governanca/testes quando a fase pedir.
- `android+docs`: `LavaPrimeAndroidApp/**` e docs do programa/governanca quando a fase pedir.
- `read-ref`: leitura de `LavaPrimeAndroidApp/**`, `app/main.js`, `app/styles.css`, `docs/primyo-data/contracts/**`.
- `web-core proibido`: `app/main.js`, `app/styles.css`, `app/adapters/**`, `app/demo/**`, `scripts/**`, contratos Web e UI Web.
