# Onboarding Checklist Status

## Before onboarding starts

- Product formally selected by the program: concluido
- Onboarding owner assigned: concluido
- Scope boundaries documented: concluido
- Required templates selected: concluido
- Access requirements confirmed: concluido
- Prohibitions acknowledged: concluido

## During onboarding

- `primyo/onboarding` created: concluido
- Legacy product intake completed: concluido
- Execution plan completed: concluido
- Repository and environment mapping recorded: concluido
- Database, permissions, and integrations mapped: concluido
- Main screens and flows documented: concluido
- Findings linked to evidence: concluido
- Open questions recorded: concluido
- Product stage and classification recorded: concluido
- Maturity scoring completed by dimension: concluido

## Before onboarding closes

- Audit report completed: concluido
- Adequacy plan completed: concluido
- Required outputs assembled: concluido
- Critical and high risks highlighted: concluido
- Approval package reviewed: parcial, depende revisao de governanca
- No product change executed without approval: concluido
