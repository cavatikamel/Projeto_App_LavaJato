# LP-DEPLOY-GOV-010

## Titulo

`LP-DEPLOY-GOV-010 - Netlify Staging Branch Deploy Manual Configuration`

## Objetivo

Consolidar um guia operacional final para o usuario configurar manualmente o branch deploy de `staging` no Netlify sem alterar producao, runtime, Supabase ou DNS.

## Escopo autorizado

- documentacao de deploy e governanca;
- consolidacao de checklist operacional;
- reforco de protecao da branch `main` e do dominio `app.lavaprime.com.br`.

## Fora de escopo

- `push`
- merge
- deploy manual
- alteracao de Netlify
- alteracao de runtime
- alteracao de `netlify.toml`
- alteracao de env
- alteracao de Supabase
- alteracao de producao

## Entregas previstas

- runbook final do painel Netlify;
- atualizacao da estrategia recomendada para branch deploy;
- instrucao objetiva para capturar a URL real de staging;
- propagacao do bloqueio remanescente da baseline de `Service Order`.
