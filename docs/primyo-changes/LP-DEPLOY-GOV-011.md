# LP-DEPLOY-GOV-011

## Titulo

`LP-DEPLOY-GOV-011 - Netlify Staging Remote Smoke Proof`

## Objetivo

Validar remotamente a URL real de staging do Netlify, confirmar que o ambiente basico de homologacao esta acessivel e registrar o estado da baseline publicada.

## Escopo autorizado

- validacao remota do staging;
- comprovacao de URL, branch e commit publicados;
- classificacao da baseline remota;
- atualizacao documental de deploy, `Service Order`, governanca e testes.

## Fora de escopo

- push
- merge
- deploy manual
- alteracao de Netlify
- alteracao de runtime
- alteracao de `netlify.toml`
- alteracao de env
- alteracao de Supabase
- alteracao de producao
