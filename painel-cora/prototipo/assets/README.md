# Logo Cora — coloque o arquivo aqui

Coloque a logo oficial nesta pasta, com **exatamente um** destes nomes:

- `cora-logo.svg`  ← preferível (qualidade perfeita, adapta ao tema)
- `cora-logo.png`  ← alternativa (use fundo transparente)

Depois de subir o arquivo, avise que eu o embuto (data-URI) no protótipo
(`painel-cora/prototipo/index.html`) e substituo a marca vetorial atual em
todos os pontos: barra superior, estado vazio, "Nova tarefa" e rodapé.
