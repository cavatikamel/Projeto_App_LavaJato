# Biblioteca de avatares (PNG)

Coloque aqui as imagens dos avatares (bichinhos), em **PNG**.

## Como nomear
Use o nome do animal, minúsculo, sem espaços/acentos — vira o rótulo na tela:
- `capivara.png`, `raposa.png`, `coruja.png`, `gato.png`, `sapo.png`,
  `panda.png`, `pinguim.png`, `urso.png`, `tucano.png`, `preguica.png` ...

(Ordem de exibição = ordem alfabética do nome do arquivo. Se quiser controlar a
ordem, prefixe com número: `01-capivara.png`, `02-raposa.png`, ...)

## Formato recomendado
- **Quadrado** (1:1), ex.: 256×256 ou 512×512.
- Fundo transparente **ou** sólido — o app recorta em círculo automaticamente.
- Peso: de preferência < 100 KB cada (elas serão embutidas no protótipo).

Depois de subir os arquivos, avise que eu embuto todos como data-URI na
biblioteca de avatares do cadastro de solucionadores
(`painel-cora/prototipo/index.html`) e removo os avatares provisórios em SVG.
